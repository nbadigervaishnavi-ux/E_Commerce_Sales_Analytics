# 📊 E-Commerce Sales & Performance Analysis

An interactive *Power BI e-commerce analytics project* designed to transform raw transactional data into meaningful business insights through data visualization, KPI analysis, and interactive reporting.

The project focuses on understanding *sales performance, order trends, product categories, seller performance, customer reviews, and geographic distribution*, followed by data-driven business recommendations.

---

## 🎯 Project Objective

The objective of this project is to analyze e-commerce sales data and answer key business questions such as:

- How is overall sales performance changing over time?
- Which product categories contribute the most to sales and orders?
- Which sellers generate higher sales?
- How many customers and orders does the business serve?
- What is the average order value?
- How does customer satisfaction vary based on review scores?
- Which locations have higher order activity?
- What business actions can be derived from the analysis?

## 📂 Dataset

This project uses a public e-commerce dataset containing information related to:

- Orders
- Order items
- Products
- Customers
- Sellers
- Payments
- Reviews
- Geolocation
- Product category translations

The data was imported into Power BI and transformed using *Power Query* before creating the analytical data model and dashboard.
